Delphi → contrato

O contrato do seu sistema Delphi, lido aqui no navegador

Telas, componentes, eventos, SQL e o que falta, num JSON que o sistema novo tem de honrar. Funciona no Windows, no Mac e no Linux, sem instalar nada.

Seu arquivo não sai deste computador. Ele é lido pelo próprio navegador, com o mesmo programa em Python da linha de comando rodando em WebAssembly. A página não tem servidor que receba arquivo: depois de carregada, ela só busca os próprios arquivos e nunca envia o conteúdo para lugar nenhum.

1. Escolha o sistema

Arraste aqui o .exe, .dll ou .bpl, o .zip do projeto ou os .dfm.

Sem o fonte, o executável dá as telas, os eventos e o SQL dos componentes. Com o fonte (.zip com .dpr, .pas e .dfm), também cada clique ligado ao SQL que ele alcança.

Carregando o motor (Python no navegador, cerca de 6 MB na primeira visita)…

2. O contrato

Telas

Clique num componente com contorno: aparece o evento, a rotina e a operação do contrato (tabelas e SQL que o clique alcança).
